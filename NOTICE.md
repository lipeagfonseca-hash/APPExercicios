# Avisos de terceiros

## Catálogo de exercícios

Os **dados** (nomes, grupos musculares, instruções) em `data/exercises/` vêm do
dataset [hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset),
licenciado sob MIT.

As **mídias** (miniaturas e GIFs) são propriedade da **Gym visual**
(https://gymvisual.com/) e foram redistribuídas pelo dataset com permissão
específica. Por isso **não estão neste repositório**. Para rodar o app
localmente, baixe-as com:

```bash
node scripts/fetch-exercise-media.cjs
```

O uso público ou comercial dessas mídias depende de licença própria da Gym visual
(https://gymvisual.com/content/3-terms-and-conditions-of-use).
